# Wond v0.4.0

Fourth public release of Wond. This release adds a first-class personal profile and personal memory workspace, hardens sync and release privacy checks, and simplifies the iOS companion app around the workflows that are now backed by the Mac dashboard.

## Highlights

- Added a personal profile workspace for durable identity, work, preference, boundary, rhythm, and current-focus fields.
- Added personal memory records with candidate review, confirmation, evidence links, conflict detection, hard delete, and privacy sensitivity levels.
- Added people files with aliases and explicit speaker links. Voice identity remains a reviewed evidence link instead of an automatic person merge.
- Injected confirmed personal memories and profile fields into local Q&A, search indexing, daily reports, and long-term summaries.
- Added dashboard controls for memory inbox review, manual memory creation, profile editing, people files, conflict handling, and personal-memory privacy summaries.
- Added local heuristic candidate extraction from configured sources such as mobile capture, messages, mail, calendar, and AI/media analysis records.
- Hardened sync handling, speaker cleanup paths, audio preprocessing, and dashboard diagnostics around privacy-safe release behavior.
- Added the read-only `wond release-audit` / `wond privacy-audit` pre-release check for tracked runtime files, secret-like literals, ignored runtime paths, and local path leaks.
- Removed the stale iOS speaker-review tab and related localization strings so mobile no longer exposes a dead-end workflow.
- Release installer asset for macOS: `Wond-0.4.0-macos.zip`.
- Release updater asset for existing installs: `Wond-0.4.0-macos-update.zip`.

## Install

1. Download `Wond-0.4.0-macos.zip` from the GitHub release.
2. Unzip it.
3. Double-click `install.command`.

## Update Existing Install

1. Download `Wond-0.4.0-macos-update.zip` from the GitHub release.
2. Unzip it.
3. Double-click `Update Wond.command`.

## Upgrade Notes

- Existing `config.json`, `data/`, local databases, reports, mobile sync imports, speaker samples, model caches, and other runtime files are preserved during install and update.
- The new personal-memory tables are added through SQLite schema migration v4.
- Confirmed personal memories can be used by local Q&A, reports, and search; candidates remain reviewable until confirmed.
- High-sensitivity personal facts are kept behind explicit review and can be hard-deleted from the dashboard.
- The iOS app keeps Mac-backed local Q&A and capture flows, but speaker review is now managed from the Mac dashboard.
- This release ships as an unsigned macOS command-package zip. If macOS blocks double-click execution, right-click the command and choose Open.

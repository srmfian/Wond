# Wond v0.2.0

Second public release of Wond. This release turns the dashboard into a practical daily operating surface and adds the migration/version plumbing needed for safer upgrades.

## Highlights

- Consolidated dashboard navigation into seven main workspaces: Today, Daily Workbench, Projects, Audio, Sources, Search, and Setup.
- Added setup wizard, Action Inbox / Daily Workbench, project memory, Meeting Mode, Privacy & Retention Center, and Speaker training loop.
- Preserved old dashboard hash routes while moving repeated pages into workspace-level subnavigation.
- Added formal SQLite schema migrations and tests for upgrade behavior.
- Split large implementation files by moving dashboard HTML into `wond/dashboard_html.py` and iOS capture support types into `CaptureStoreSupport.swift`.
- Declared Python dependencies and optional extras for local audio, speaker tooling, and evaluation workflows.
- Unified Python and iOS version metadata for release packaging.
- Release installer asset for macOS: `Wond-0.2.0-macos.zip`.

## Install

1. Download `Wond-0.2.0-macos.zip` from the GitHub release.
2. Unzip it.
3. Double-click `install.command`.

The installer copies Wond to `~/Applications/Wond`, creates a private Python virtual environment, installs Wond in editable mode, initializes `config.json`, and can load the dashboard, sync, and monitor LaunchAgents.

Set `WOND_INSTALL_DIR=/path/to/Wond` before running `install.command` to choose another install directory.

## Upgrade Notes

- Existing `config.json`, `.venv/`, and `data/` are preserved during install.
- The dashboard still accepts old routes such as `#speaker-training`, `#privacy`, `#reports`, and `#sync`; they now highlight their parent workspaces.
- SQLite schema changes are applied through the migration runner when Wond opens the store.
- Advanced local audio and speaker workflows still require the optional dependencies and local models described in the README.
- This release ships as an unsigned macOS command-package zip. If macOS blocks double-click execution, right-click the command and choose Open.

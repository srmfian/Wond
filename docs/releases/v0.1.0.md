# Wond v0.1.0

First public release of Wond as a local-first personal context system.

## Highlights

- macOS local context collection, reporting, dashboard, doctor, and LaunchAgent service commands.
- iPhone sync server support for encrypted capture uploads and local Ask requests.
- Local-first AI defaults through Ollama and MLX-based audio paths, with OpenAI-compatible analysis still available as an optional backend.
- Release installer asset for macOS: `Wond-0.1.0-macos.zip`.

## Install

1. Download `Wond-0.1.0-macos.zip` from the GitHub release.
2. Unzip it.
3. Double-click `install.command`.

The installer copies Wond to `~/Applications/Wond`, creates a private Python virtual environment, installs Wond in editable mode, initializes `config.json`, and can load the dashboard, sync, and monitor LaunchAgents.

Set `WOND_INSTALL_DIR=/path/to/Wond` before running `install.command` to choose another install directory.

## Notes

- The installer preserves existing `config.json`, `.venv/`, and `data/` when updating an existing install.
- This release ships as an unsigned macOS command-package zip. If macOS blocks double-click execution, right-click the command and choose Open.
- Advanced audio transcription, diarization, speaker matching, and local model execution still require the local model/toolchain dependencies described in the README, such as Ollama, ffmpeg, MLX Audio, and SpeechBrain/Torch where configured.

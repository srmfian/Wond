# Wond v0.3.1

Patch release for the Wond iOS companion app. This release fixes two mobile regressions found after v0.3.0: Tailscale sync over HTTP was blocked by iOS App Transport Security, and location display could remain stuck on the transient "Resolving address" state.

## Highlights

- Added a scoped iOS App Transport Security exception for local networking and Tailscale MagicDNS domains under `*.ts.net`.
- Fixed iPhone sync failures that showed "The resource could not be loaded because the App Transport policy requires the use of a secure connection" when using the recommended Tailscale HTTP sync URL.
- Retried reverse geocoding when `CLGeocoder` is already busy instead of dropping the address lookup.
- Reused a nearby previously resolved address for short-interval nearby location updates.
- Added a coordinate fallback when reverse geocoding fails, so the iOS UI no longer remains stuck on "Resolving address".
- Release installer asset for macOS: `Wond-0.3.1-macos.zip`.
- Release updater asset for existing installs: `Wond-0.3.1-macos-update.zip`.

## Install

1. Download `Wond-0.3.1-macos.zip` from the GitHub release.
2. Unzip it.
3. Double-click `install.command`.

## Update Existing Install

1. Download `Wond-0.3.1-macos-update.zip` from the GitHub release.
2. Unzip it.
3. Double-click `Update Wond.command`.

## Upgrade Notes

- Existing `config.json` and `data/` are preserved during install and update.
- The iOS app still follows the user's system language and falls back to English.
- For iPhone sync, prefer a Tailscale MagicDNS URL such as `http://mac-name.tailnet-name.ts.net:8765/upload`.
- This release ships as an unsigned macOS command-package zip. If macOS blocks double-click execution, right-click the command and choose Open.

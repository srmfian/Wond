# Wond v0.3.0

Third public release of Wond. This release focuses on multilingual product polish across the web dashboard and iOS app, plus safer release packaging for common macOS install paths.

## Highlights

- Added multilingual dashboard support for English, Simplified Chinese, Japanese, and Korean.
- Set the dashboard initial language to English and added a Settings language selector.
- Localized remaining dashboard runtime text, including tooltips, index/search states, keywords, question prompts, empty states, and status labels.
- Added iOS and watchOS localization resources for Simplified Chinese, Japanese, and Korean while keeping English as the default development language.
- Localized iOS dynamic text that does not flow through SwiftUI string literals, including sync status, ask/review errors, recording state, location state, notification text, and duration labels.
- Added localized iOS permission prompt strings for microphone and location usage.
- Updated release installers to prefer `/Applications/Wond`, reuse legacy `~/Applications/Wond` installs when needed, and provide an update package for existing installs.
- Fixed the speaker training empty-state handling so empty review queues render cleanly.
- Release installer asset for macOS: `Wond-0.3.0-macos.zip`.
- Release updater asset for existing installs: `Wond-0.3.0-macos-update.zip`.

## Install

1. Download `Wond-0.3.0-macos.zip` from the GitHub release.
2. Unzip it.
3. Double-click `install.command`.

The installer prefers `/Applications/Wond`, creates a private Python virtual environment, installs Wond in editable mode, initializes `config.json`, and can load the dashboard, sync, and monitor LaunchAgents. If an existing legacy install is found at `~/Applications/Wond`, the installer reuses it and tries to create a `/Applications/Wond` link; if `/Applications/Wond` is not writable, it falls back to `~/Applications/Wond`.

Set `WOND_INSTALL_DIR=/path/to/Wond` before running `install.command` to choose another install directory.

## Update Existing Install

1. Download `Wond-0.3.0-macos-update.zip` from the GitHub release.
2. Unzip it.
3. Double-click `Update Wond.command`.

The update package replaces release-managed app files only. It preserves `config.json`, `data/`, local databases, reports, mobile sync imports, speaker samples, model caches, and other runtime files under the data directory. It reuses the existing `.venv` and may refresh dependency metadata if the new Wond version needs it.

The updater automatically checks `/Applications/Wond` and `~/Applications/Wond`. If Wond is installed somewhere else, set `WOND_INSTALL_DIR=/path/to/Wond` before running `Update Wond.command`.

## Upgrade Notes

- Existing `config.json` and `data/` are preserved during install and update.
- Dashboard language preference is stored locally in the browser and defaults to English for first-time users.
- The iOS app follows the user's system language and falls back to English.
- The dashboard still accepts old routes such as `#speaker-training`, `#privacy`, `#reports`, and `#sync`; they now highlight their parent workspaces.
- This release ships as an unsigned macOS command-package zip. If macOS blocks double-click execution, right-click the command and choose Open.
